# daily-builds

Daily small, runnable projects across modern web, backend, DevOps, and tooling.

## Rules

- One dated directory per project: `YYYY-MM-DD-slug/`
- Include `README.md`, source code, and runnable validation or test
- Prefer TypeScript, React, Next.js, TanStack, Node.js, PostgreSQL, Docker
- Rotate Python, Go, Bash, and vanilla HTML/CSS/JavaScript
- No secrets, private data, or empty commits
